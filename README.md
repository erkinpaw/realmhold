# Strategy1: Hex Realms

RTS-стратегия в мире Minecraft (Fabric, MC 26.2). Персонажа нет: вы — камера над землёй.
Мир вокруг спавна разбит на шестиугольные провинции (≈83 блока), на них живут пять держав ИИ и ваша.

## Управление (режим стратега включается сам при входе; G — выйти/войти)

| Клавиша | Действие |
|---|---|
| WASD / стрелки / края экрана | двигать камеру (Shift — быстрее) |
| колесо | высота камеры |
| Q / E | поворот камеры |
| ЛКМ / рамка ЛКМ | выбрать воинов (Shift — добавить) |
| ПКМ по земле / по врагу | идти / атаковать |
| H или Пробел | стоять |
| Ctrl+A | выбрать всех |
| 1–5 | нанять воина в провинции под камерой (иначе в столице) |
| Tab | панель стройки ↔ армии |
| ЛКМ по зданию | выбрать его (казармы — найм, мастерская — осадные орудия, порт — корабли, башня/стена — снять лучника, «Снести») |
| ПКМ по своему кораблю (выбраны воины) | посадить на корабль |
| ПКМ по своей башне/стене (выбраны лучники) | поставить лучников на неё |
| ПКМ по вражескому зданию | ломать его (осадные орудия кидают камни) |
| ПКМ кораблём по суше | доплыть до берега и высадить воинов |
| R (при стройке) | повернуть здание |
| M | карта держав (провинции, постройки, эпохи, армия, дипломатия) |
| B | границы провинций в мире |

## Игра

- **Ресурсы**: еда, дерево, камень, железо, золото. Каждый ход (1 минута) провинции дают их по местности
  (равнины, лес, горы, пустыня, снега, болота); богатые залежи дают намного больше — за них и воюют.
- **Развитие**: хозяйство (+50% дохода за уровень), укрепления, гарнизоны, эпохи I–IV
  (открывают мечников, рыцарей, гвардию и большую армию). Воины едят по 1 еде за ход.
- **Захват**: приведите воинов к столбу в центре соседней провинции. Гарнизон выйдет на бой;
  когда он разбит, держите воинов в круге, пока полоса не заполнится.
- **Войны**: ИИ строится, нанимает войска, занимает вольные земли, объявляет войны (охотнее из-за залежей)
  и ходит в набеги — на ваши провинции рядом с камерой реальным отрядом, на далёкие — «на бумаге».

Команды: `/strategy info`, `/strategy turn` и `/strategy give <ресурс> <число>` (для операторов).

## Стройка

Вкладка «Стройка» (Tab): выберите постройку и кликните место на своей земле — здание строится блок за блоком.

| Постройка | Что даёт |
|---|---|
| Ферма / Лесопилка / Шахта | +8 еды / +8 дерева / +5 камня и +3 железа за ход |
| Казармы | найм воинов у их двери |
| Осадная мастерская (эпоха II) | катапульты (II) и требушеты (III) |
| Порт (на берегу, пирс в воду) | транспорт (8 воинов) и боевой корабль (эпоха II, 4 воина + катапульта на палубе) |
| Башня деревянная / каменная (II) | до 2 / 4 лучников, бьют врагов и корабли |
| Стена деревянная / каменная (II) | ставится двумя кликами (начало и конец), лучники — 1 на 3 блока |
| Тропа | юниты по ней на 40% быстрее, через воду — мостки |

Столицы ИИ обнесены стенами с воротами и башнями с лучниками. Осадные орудия и боевые корабли
ломают их камнями (в стенах появляются пробоины, разрушенное рушится).

Для пробы казна вашей державы один раз получает по 20 000 каждого ресурса (`Rules.TEST_STOCK`).

## Сборка и запуск

Нужен JDK 25+ (`JAVA_HOME`). `./gradlew runClient` — игра; `./gradlew runClientGameTest` — автотест
(реальный мир: все постройки, найм из казарм/мастерской/порта, лучники на башне, десант на корабле,
башня против кораблей, осада катапультами и требушетом; скриншоты в `build/run/clientGameTest/screenshots`).

Основа (API 26.2, интерфейс в стиле пергамента, приёмы с сущностями и сетью) взята из
[Roads-Harbors](https://github.com/erkinpaw/Roads-Harbors).
