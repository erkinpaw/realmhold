# Realmhold

RTS-стратегия в мире Minecraft (Fabric, MC 26.2): смесь Stronghold и «Казаков». Персонажа нет — вы камера над землёй.
Мир разбит на шестиугольные провинции; ваша держава и державы ИИ растут, торгуют, воюют и отбиваются от нежити.

## Режимы (выбираются при создании мира в своём меню)

| Режим | Суть |
|---|---|
| ⚔ Завоевание | державы ИИ воюют за земли и залежи, ходят в набеги; захватывайте провинции |
| ☠ Осада нежити | днём добыча и стройка, ночью волны зомби, скелетов, громил — каждая сильнее; неудержанные земли нежить отбирает (провинции с замком или башней не отдаются) |
| ⚖ Торговые державы | без войн: кто первым разбогатеет на рынке, караванах и ремёслах (цель — прирост богатства, таблица лидеров в верхней панели) |
| ✿ Развитие | только вы и земля, стройтесь в мире |

Можно играть с друзьями по сети (кооп: игроки присоединяются к одной державе) против ИИ.
Число держав ИИ настраивается в меню нового мира. Стандартные деревни не генерируются — вместо них
столицы держав ИИ: замок, стены, башни с лучниками, дома, ферма, казармы и жители за работой.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки / края экрана | камера (Shift — быстрее), колесо — высота, Q / E — поворот |
| ЛКМ / рамка ЛКМ | выбрать воинов (Shift — добавить), Ctrl+A — всех |
| ПКМ | по земле — идти, по врагу — атаковать, по вражескому зданию — ломать, по своему кораблю — посадить, по своей башне/стене — поставить лучников, кораблём по суше — высадка |
| H / Пробел | стоять |
| Tab | вкладки: хозяйство, войско, оборона, дороги, армия |
| R (при стройке) | повернуть здание |
| M | глобальная карта (M ещё раз — назад): земля как она есть (увиденная), владения, постройки; двойной клик — перелететь |
| миникарта (правый нижний угол) | ЛКМ — перенести камеру (можно тянуть), ПКМ — послать туда выбранных воинов |
| наведение мыши | на любую иконку (постройки, найм, ресурсы и жители вверху, миникарта) — подсказка: цена, что делает, что нужно |
| B | границы провинций в мире |
| G | выйти из режима стратега / вернуться |

## Хозяйство

Ресурсы — еда, дерево, камень, железо, золото — добывают **крестьяне**: они приходят в дома, сами
идут на свободные работы и носят добычу на склад. Ничего не делающие крестьяне идут в рекруты при найме.

| Постройка | Что даёт |
|---|---|
| Дом / Склад | места для жителей / куда носят добычу |
| Ферма, Лесоруб | еда (поле растёт), дерево (рубят деревья вокруг) |
| Каменоломня, Железный и Золотой рудник | ставятся у залежей камня, железа, золота (видны на земле и на карте) |
| Рынок | продажа и покупка товаров по плавающим ценам, караваны к чужим столицам за золотом |
| Казармы, Кузница | найм воинов; кузница открывает сильных воинов и мастерскую |
| Осадная мастерская | катапульты и требушеты, ломающие стены |
| Порт | транспорт и боевой корабль; корабли сами ищут путь по воде |
| Башни и стены (дерево, камень после каменоломни) | лучники на них; башни улучшаются: баллиста, катапульта, огненная жаровня |
| Тропа, Мост | быстрая дорога; мост через воду |

Для пробы казна получает по 20 000 каждого ресурса (`Rules.TEST_STOCK`).
Команды операторов: `/strategy info | mode | wave | turn | give <ресурс> <число>`.

## Сборка и запуск

Нужен JDK 25+ (`JAVA_HOME`). `./gradlew runClient` — игра; `./gradlew runClientGameTest` — автотесты в реальном мире
(меню, стройка и найм, экономика и доставки, осада и волны, корабли и пути, торговля, карта, города ИИ, подсказки и миникарта;
скриншоты в `build/run/clientGameTest/screenshots`).

Основа (API 26.2, интерфейс-пергамент, поиск пути кораблей) взята из
[Roads-Harbors](https://github.com/erkinpaw/Roads-Harbors).
